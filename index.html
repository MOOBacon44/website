Statement of purpose

ตั้งแต่เด็ก หนูมีความชื่นชอบในการถ่ายทอดเรื่องราวและประสบการณ์ผ่านงานศิลปะ เพราะหนูรักในการได้แบ่งปันความคิดสร้างสรรค์ให้ผู้อื่นได้รับรู้ จนกระทั่งในช่วงมัธยมศึกษาปีที่ 4 หนูได้มีโอกาสเข้าร่วมกิจกรรมการสร้างเกมด้วยโปรแกรม Unity จุดนั้นเองที่ทำให้หนูค้นพบว่า เกม คือสื่อที่สามารถรวมเอางานศิลปะ การเล่าเรื่อง และเทคโนโลยีเข้าด้วยกันได้อย่างลงตัว จากจุดเริ่มต้นนั้น หนูได้มุ่งมั่นพัฒนาทักษะการสร้างเกมอย่างจริงจัง จนได้รับเลือกเป็นตัวแทนโรงเรียนเข้าร่วมการแข่งขัน Thailand - Japan Game Programming Hackathon 2024 ในระดับนานาชาติ ภายใต้โจทย์ "Net Zero" โดยทีมของหนูได้ถ่ายทอดแนวคิดนี้ผ่านเกมจำลองการบริหารธุรกิจเฟอร์นิเจอร์ไม้ ซึ่งผู้เล่นต้องรักษาสมดุลระหว่างการเติบโตทางเศรษฐกิจและการดูแลสิ่งแวดล้อมไปพร้อมกัน หากขาดสมดุลด้านใดด้านหนึ่ง เกมจะจบลงทันที เพื่อสะท้อนถึงผลกระทบที่เกิดขึ้นจากการสูญเสียสมดุลในธรรมชาติ ประสบการณ์ครั้งนี้ช่วยผลักดันให้หนูได้นำทักษะด้าน Gameplay Design และ Programming มาประยุกต์ใช้แก้ปัญหาภายใต้ข้อจำกัดของเวลา หนูเรียนรู้และสนุกไปกับการออกแบบระบบการเล่น (Game Mechanics) ให้มีความท้าทาย ลงตัว และสามารถสื่อสารสาระสำคัญไปยังผู้เล่นได้อย่างน่าสนใจ รวมถึงได้ฝึกฝนทักษะการทำงานเป็นทีมและการแก้ปัญหาเฉพาะหน้าอย่างมีประสิทธิภาพ การตัดสินใจเข้าศึกษาต่อในวิทยาลัยศิลปะ สื่อ และเทคโนโลยี สาขาดิจิทัลเกม มหาวิทยาลัยเชียงใหม่ เกิดจากความเชื่อมั่นในหลักสูตรที่มุ่งเน้นการพัฒนาทักษะเชิงลึกทั้งด้านศาสตร์และศิลป์ของการทำเกม อีกทั้งสถาบันยังมีความเชื่อมโยงกับเครือข่ายอุตสาหกรรมเกม ซึ่งจะเป็นโอกาสสำคัญในการเรียนรู้ประสบการณ์จริงจากผู้เชี่ยวชาญ และเตรียมความพร้อมสู่การทำงานในอุตสาหกรรมได้อย่างเป็นมืออาชีพ เป้าหมายในอนาคตของหนู คือการเติบโตไปเป็น Game Designer และ Game Programmer มืออาชีพ ที่สามารถนำความรู้และแรงบันดาลใจที่มีมาสร้างสรรค์ผลงานเกมที่มาจากความรักและตั้งใจของหนู หนูตั้งใจที่จะพัฒนาเกมที่ไม่เพียงแต่ให้ความสนุก แต่ยังสามารถถ่ายทอดคุณค่า ข้อคิด และประสบการณ์แปลกใหม่ให้แก่ผู้เล่นได้ค่ะ
